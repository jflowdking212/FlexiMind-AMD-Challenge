# Lablab Submission Checklist

## Registration / Participation
- [ ] Lablab profile complete
- [ ] Discord connected if required by the event
- [ ] Bliss AI Labs solo team active
- [ ] challenge eligibility confirmed

## Project Form
- [ ] title finalized
- [ ] short description finalized
- [ ] long description finalized
- [ ] categories accurate
- [ ] technologies used are actually implemented
- [ ] GitHub repository is public
- [ ] additional information updated
- [ ] optional Mini Challenge evidence added only if completed

## Repository
- [ ] public URL works in logged-out/private browser
- [ ] README renders correctly
- [ ] setup instructions reproduce
- [ ] no secrets
- [ ] no database/Redis dumps
- [ ] no proprietary backup folders
- [ ] challenge code is understandable
- [ ] AMD path is clearly identified
- [ ] benchmark data is included
- [ ] limitations are documented

## Demo
- [ ] live demo URL works, if required
- [ ] demo video works, if required
- [ ] screenshots are readable
- [ ] AMD execution evidence is visible
- [ ] no secret values visible

## Claims
- [ ] no technology is claimed before integration
- [ ] no fabricated benchmark number
- [ ] no unsupported performance claim
- [ ] current vs planned features clearly separated

## Final
- [ ] all required form fields complete
- [ ] repository commit/tag recorded
- [ ] links tested
- [ ] final submission screenshot saved
