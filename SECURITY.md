# Security

This repository is public and challenge-focused.

## Reporting

Do not publish credentials, customer information, or exploitable production details in a public issue.

If you discover sensitive information in this repository, contact the repository owner privately through the GitHub account associated with this project.

## Scope

The public repository should contain challenge-specific code and documentation only. Production credentials, production data, database dumps, backup archives, and proprietary application internals are out of scope and must not be committed.
